# Student Performance Analyzer

A beginner-friendly Python software lab case study analyzing fictional student marks, attendance, and study hours.

## Features
- Reads student records from CSV
- Calculates totals, averages, percentages, and illustrative performance categories
- Uses core Python, NumPy, pandas, and Matplotlib
- Searches student records and filters low attendance
- Creates charts and saves analyzed data and a summary report

## Files
- `Student_Performance_Analyzer.ipynb` — main notebook and demonstration
- `data/student_data.csv` — fictional sample dataset
- `outputs/` — generated reports are saved here when the notebook runs

## Run in VS Code
1. Install Python 3.
2. Install the **Python** and **Jupyter** extensions in VS Code.
3. Open this project folder in VS Code.
4. In the terminal, run: `python -m pip install -r requirements.txt`
5. Open `Student_Performance_Analyzer.ipynb`, choose a Python 3 kernel, and run cells from top to bottom.

If your terminal uses `python3`, run `python3 -m pip install -r requirements.txt`.

## Required concepts
Variables, operators, strings, lists, tuples, sets, dictionaries, functions, files, NumPy, pandas, and Matplotlib.

## Notes
The supplied data is fictional. Adjust thresholds to match your institution's rules. Correlation is not proof of causation.
